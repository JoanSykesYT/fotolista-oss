# Cómo contribuir a FotoLista OSS

¡Gracias por tu interés! Las mejoras, correcciones, documentación y pruebas son bienvenidas.

1. Revisa los issues existentes; si es un problema nuevo, abre uno explicando qué ocurrió.
2. Describe tu propuesta antes de hacer cambios grandes.
3. Crea una rama con un nombre descriptivo y realiza el cambio.
4. Prueba en un navegador actualizado y confirma que las medidas y los JPG generados sean correctos.
5. Abre un pull request con explicación, pasos de prueba y, si aporta valor, capturas de pantalla.

No incluyas fotografías privadas, datos personales, secretos, claves de API ni material protegido sin permiso. Usa fotografías de prueba propias o con licencia compatible.

## Ideas para colaborar

- Vista previa de la zona de recorte.
- Pruebas automatizadas de JPG y ZIP.
- Traducciones.
- Mejoras de accesibilidad.
- Optimización de memoria al procesar fotos grandes.

## Código de conducta

Comunícate con respeto. No se permite acoso, amenazas ni divulgación de información privada. El responsable del repositorio puede moderar conversaciones inapropiadas.
